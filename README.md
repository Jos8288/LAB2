# Personal Portfolio – Lab 2

## Project Description

This project is an extension of my personal portfolio website created in Lab 1. The website presents my background, skills, projects and contact information.

In Lab 2, I added JavaScript to make the contact form interactive, including form validation, error messages and feedback to the user.

## Target Grade

**Grade 3**

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Lab 2 Features

- Full Name validation with a minimum of 2 characters
- Email validation
- Topic selection with three options
- Comments validation with a minimum of 15 characters
- Live character counter for comments
- Optional website field with URL validation
- Error messages and visual feedback for valid and invalid fields
- Personalized success message that disappears after 4 seconds
- Submit button that validates the form
- Clear button that resets the form and validation messages
- Responsive form layout and accessible labels

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Scroll to the contact section to test the interactive form.

No installation or backend server is required.

The form is a frontend demonstration and does not send or store messages.
