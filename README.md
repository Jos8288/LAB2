# Personal Portfolio – Lab 2

## Project Description

This project is an extension of my personal portfolio website created in Lab 1. The website presents my background, skills, projects and contact information.

In Lab 2, I will add JavaScript to make the contact form interactive.

## Target Grade

Grade 3

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Planned Lab 2 Features

- Form validation with clear error messages
- Visual feedback for valid and invalid fields
- Live character counter for comments
- Personalized success message
- Submit and Clear functionality
- Responsive and accessible form design

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.

No installation or backend server is required.
